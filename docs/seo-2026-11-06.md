# SEO update, November 6, 2026

## Changes

- HRG Prefab builds 99 routes as HTML using the same React page components shown in the browser. The sitemap contains 76 canonical pages; 23 model configuration pages stay out of the sitemap and use noindex.
- Each page has its own title, description, canonical URL, social preview tags, and Organization/WebSite/WebPage structured data. Interior pages have breadcrumbs.
- The homepage and `/faq` include readable answers about prefab ADUs, materials pricing, scope, contractors, property review and permits. Footer links connect visitors and crawlers to FAQs and services.
- The Vercel catch-all homepage rewrite is removed. Existing routes have generated HTML, robots.txt is text, sitemap.xml is XML, and unknown URLs use a noindex 404 page. Existing estimate-subdomain routing is retained.
- The remodeling site has a visible FAQ section and `/faq`, a 12-page sitemap, linked FAQs, social metadata and structured data. Existing Article markup is preserved.
- No hidden keyword pages, invented reviews, or promises of Google ranking/AI inclusion were added.
